# 默认应用重置修复工具 v3.0 使用说明

## 问题说明
Windows 系统更新或重启后，默认浏览器、压缩软件、视频播放器等经常被自动重置为系统默认应用。

**根本原因**：Windows 10/11 的默认应用带有 UserChoice 哈希校验，手动改注册表哈希不匹配，系统会直接忽略并重置。

## 工具原理
集成 SetUserFTA 工具，自动计算正确的哈希值，让设置真正生效；配合注册表策略锁定，防止系统再次重置。

## 使用方法

### 启动
**双击 `启动修复工具.bat`**，弹出权限提示时点"是"。

### 推荐操作：一键全部修复
1. 菜单选 **1（一键全部修复）**
2. 脚本自动检测你安装的软件
3. 每一类（浏览器/压缩/视频）选择一个编号
4. 自动完成设置 + 防重置锁定
5. **重启电脑**生效

### 菜单选项说明

| 选项 | 功能 | 适用场景 |
|------|------|----------|
| 1 | 一键全部修复 | 首次使用，三类应用都要修 |
| 2 | 设置默认浏览器 | 只修浏览器 |
| 3 | 设置默认压缩软件 | 只修压缩软件 |
| 4 | 设置默认视频播放器 | 只修视频播放器 |
| 5 | 仅启用防重置策略 | 已经手动设置好了，只想锁定不被重置 |
| 6 | 查看当前文件关联 | 检查哪些扩展名关联了什么程序 |
| 7 | 清理损坏的注册表项 | 设置保存不了时先清一下 |
| 8 | 备份当前配置 | 导出当前关联，方便恢复 |
| 9 | 重新下载工具 | 工具文件损坏时 |
| 0 | 退出 | 退出并自动清理临时文件 |

## 支持的软件

### 浏览器
- Chrome / Edge / Firefox

### 压缩软件
- WinRAR / 7-Zip / Bandizip

### 视频播放器
- PotPlayer / VLC / MPC-HC

> 如果你用的软件不在列表中，可手动添加 ProgID 或告知开发者补充。

## 修复后验证

1. 重启电脑
2. 打开 设置 → 应用 → 默认应用
3. 确认你的设置还在
4. 双击对应类型的文件，看是否用你设置的程序打开

## 注意事项

⚠️ **必须以管理员身份运行**（bat启动器会自动请求）

⚠️ **修改后需要重启电脑**才能完全生效

⚠️ 脚本退出时会自动删除下载的 SetUserFTA 工具，不留垃圾文件

⚠️ 备份文件夹会保留，里面是你导出的配置备份

## 如果还是会重置

1. 检查是否有第三方安全软件/优化软件在修改设置（360、腾讯电脑管家等）
2. 运行选项5重新应用防重置策略
3. 检查Windows是否有新的累积更新安装
4. 尝试新建一个本地用户账户测试

# Windows 默认应用重置修复工具使用说明

## 问题描述
Windows 系统在更新或重启后，用户设置的默认浏览器、图片查看器、PDF阅读器等应用经常被自动重置为微软官方应用（Edge、照片等）。

## 脚本功能
本脚本整合了7种有效的修复方案，可以解决绝大多数默认应用自动重置的问题。

## 使用方法

### 1. 运行脚本
- **右键点击** `FixDefaultAppsReset.ps1`
- 选择 **"使用 PowerShell 运行"** 或 **"以管理员身份运行"**
- 如果提示执行策略限制，请先运行以下命令（管理员PowerShell）：
  ```powershell
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  ```

### 2. 推荐操作顺序

#### 方案一：一键综合修复（推荐首次使用）
选择菜单中的 **选项1**，自动执行所有修复步骤：
- 备份当前默认应用设置
- 启用 NoOpenWith 策略（核心修复）
- 清理损坏的 UserChoice 注册表项
- 禁用 Edge 强制关联任务
- 禁用应用程序体验计划任务

#### 方案二：按需单独修复
根据具体情况选择对应选项：

| 选项 | 功能 | 适用场景 |
|------|------|----------|
| 2 | 启用 NoOpenWith 策略 | 最核心的修复，阻止系统强制重置 |
| 3 | 清理 UserChoice 注册表 | 默认应用设置无法保存时 |
| 4 | 备份当前设置 | 修改前备份，方便回滚 |
| 5 | 修复系统文件 | 系统文件损坏导致的问题 |
| 6 | 禁用 Edge 强制关联 | 浏览器/PDF总是被改回Edge时 |
| 7 | 禁用应用体验任务 | 计划任务导致重置时 |
| 8 | 从备份恢复 | 修复失败时恢复原状 |

## 修复原理说明

### 1. NoOpenWith 注册表策略（最有效）
在 `HKLM\SOFTWARE\Policies\Microsoft\Windows\Explorer` 下创建 `NoOpenWith=1`
- 阻止 Windows 自动重置文件关联
- 这是微软官方认可的策略设置

### 2. 清理 UserChoice 项
删除 `HKCU\...\FileExts\.<ext>\UserChoice` 注册表项
- 这些项包含哈希校验，损坏后会导致设置无法保存
- 删除后重新设置即可正常生效

### 3. 禁用相关计划任务
- 禁用 Application Experience 下的兼容性评估任务
- 这些任务可能在后台重置默认应用关联

### 4. 系统文件修复
- SFC 扫描修复损坏的系统文件
- DISM 修复系统映像

## 修复后的操作

1. **重启电脑**（必须）
2. 重新设置默认应用：
   - 设置 → 应用 → 默认应用
   - 按文件类型或按应用设置
3. 重启验证设置是否保留

## 注意事项

⚠️ **重要提示**
- 脚本需要管理员权限运行
- 修改注册表前会自动备份到桌面
- 如遇问题可使用选项8从备份恢复
- 建议先创建系统还原点

## 常见问题

**Q: 运行脚本后还是会重置？**
A: 请尝试：
1. 运行选项5修复系统文件
2. 检查是否有第三方软件（如杀毒、优化软件）在修改设置
3. 确认Windows更新是否有新的补丁

**Q: NoOpenWith 策略有副作用吗？**
A: 基本没有，它只是阻止系统自动重置，不影响你手动修改默认应用。

**Q: 如何完全撤销脚本的修改？**
A: 
1. 使用选项8恢复注册表备份
2. 手动将 NoOpenWith 值改为 0 或删除
3. 重新启用被禁用的计划任务
